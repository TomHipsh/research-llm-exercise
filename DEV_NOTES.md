# DEV_NOTES

General notes and future improvements for growing the repository research chatbot.

## Improvements and Future Feature Suggestions

- Use structured chat completions in prompt rendering so answers can be validated against an expected schema.
- Add prompt result validation before showing answers to the user.
- Add support for re-indexing only changed codebase sections instead of rebuilding the whole repository index.
- Develop a web app with a dedicated chat UI.
- Persist user questions in a database.
- Include conversation history in the next answer context for a more natural conversational flow.
